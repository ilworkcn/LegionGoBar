## 基础控件与快捷页

- 滑块按 XAML 导入刻度位置、频率和吸附规则，支持点击、拖动、键盘及手柄方向键提交。
- 快捷磁贴采用原型状态配色、12 px 圆角与按下反馈；支持交换顺序、隐藏与恢复、3/4/5 列和亮度显示设置，配置保存在本地。
- 字体内置 Noto Sans CJK SC，统一轮廓抗锯齿与完整 hinting 偏好；与 UWP 的文字栅格化尚未逐像素验收。
- 快捷磁贴已支持键盘与 Menu／View 手柄组合；背键辅助组合、快捷指标定制、OLED 与反应式灯光等仍未完成。

## 性能控制

- RTSS 全局帧率限制：直接调用安装目录中的 RTSSHooks64.dll，检测进程状态、读回限制值、失败恢复，运行时每 5 秒重新检测。OSD 共享内存和基础布局已移植，完整原版监控数据与图表仍未完成。
- Sticky TDP：仅自定义模式启用，按设置间隔读取 SPL/SPPT/FPPT，仅在偏移时重写；外部切换预设模式后停止维持，读取失败时延长重试间隔。
- 两项设置均已接入原有性能页，游戏配置可保存并应用；模式先于功率应用，Sticky TDP 最后应用。
- 完成原生接口替身、异常、回滚、定时策略与界面集成测试。RTSS 实际限帧与第一代 Legion Go 的功率响应仍需在具备对应环境的设备上实测。

## 游戏与电源配置

- 游戏和全局配置均支持共用、AC 与 DC 分支；未覆盖的游戏字段继承全局值。
- 按前台可执行文件匹配；打开 LegionGoBar 时保留游戏上下文，切换到未匹配程序时恢复全局配置。
- 接电或拔电时重新应用对应分支；失败限次重试，全部成功后才更新活动配置。
- 配置中的分辨率与刷新率配对测试、应用和回读，失败时恢复旧模式。
- JSON 导入导出包含全局及电源分支，兼容早期单分支 JSON。支持原项目单个 GameProfile 与 GoTweaksProfiles 版本 1／2 XML 导入，未转换的字段保留在数据中并提示，不应用。增加游戏配置保存范围选择；游戏库自动发现和原版完整配置卡片仍未移植。
- 软件回归覆盖游戏切换、全局恢复、电源变化、失败重试及导入校验；掌机实测尚未完成。

## 新增运行能力与边界

- HDR 使用 Windows 活动显示路径能力查询、回读和失败恢复；内屏优先。第一代 Legion Go 内屏无 HDR 时保持不可用。
- AMD 显示颜色使用 ADLX 驱动报告的范围和步长；包含亮度、对比度、饱和度、色温及失败恢复。Radeon Boost 分辨率比例已接线。
- RTSS OSD 使用 v2 共享内存，写入要求 v2.14 及以上原子锁；不占用其他客户端槽位，异常释放锁。已验证独立 Windows 命名内存，实际游戏叠加仍待实测。
- OSD 支持项目选择／排序、字体、颜色、透明度、列数、时钟和自定义标签。GPU/VRAM 等未接入遥测的项目显示 `--`；帧时间图表、PresentMon 与完整原版样式未移植。
- AutoTDP 实现保守 PID 路径的增益、趋势预测、平滑与逐瓦探测，读不到有效帧率时停止调节并恢复配置瓦数，切换固件预设时不抢回自定义模式。Q-Learning、SARSA、原版完整上限检测与学习数据持久化未移植；不能视为完整 AutoTDP 复刻。
- 系统电源按钮／熄屏时间已修复原控件接线；新增 AC/DC 空闲休眠及 60 秒空闲熄屏，默认关闭。系统恢复后重新计时，手柄活动阻止空闲休眠。
- 虚拟手柄／VIIPER、驱动部署、背键热键桥接、动态灯效、完整游戏检测与默认游戏配置、Lossless Scaling 实际缩放状态回读等仍未完成。

## Lossless Scaling

- 通过 Steam 注册表与 libraryfolders.vdf 查找安装目录，支持首次启动、显示窗口、保存并正常退出后重启。
- 按游戏可执行文件完整路径选择配置；支持克隆 Default 创建配置、暂存重置及每配置草稿。XML 保留未知字段，原子替换、备份、外部修改冲突保护。
- 按 LS Settings.xml 的快捷键向已核验的目标窗口发送缩放指令；不具备可靠的实际缩放状态接口，状态仅跟踪本程序发出的指令。不能据此宣称已经验证插帧或缩放生效。

## 逐项核对方式

1. 相同 Windows 缩放、主题、显示模式下打开原程序和 LegionGoBar，核对每页默认状态、展开内容、焦点、弹窗和控件尺寸。
2. 首先运行只读 `--diagnose`，保存 WMI/HID/AMD 可用能力。
3. 在掌机上逐项操作，记录请求值、实际回读、物理响应、重启后持久化、游戏切换与 AC/DC 切换。
4. 对不具备回读协议的操作记录物理证据，不以“已发送”当作成功。
5. 只有全部必需项通过才能将 full_parity_accepted 改为 true；目前不应修改此标记。
