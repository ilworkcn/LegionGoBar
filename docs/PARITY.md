## 基础控件与快捷页

- 滑块按 XAML 导入刻度位置、频率和吸附规则，支持点击、拖动、键盘及手柄方向键提交。
- 快捷磁贴采用原型状态配色、12 px 圆角与按下反馈；支持交换顺序、隐藏与恢复、3/4/5 列和亮度显示设置，配置保存在本地。
- 字体内置 Noto Sans CJK SC，统一轮廓抗锯齿与完整 hinting 偏好；与 UWP 的文字栅格化尚未逐像素验收。
- 快捷页自定义快捷键、指标选择仍未接入；RTSS、Auto TDP、Sticky TDP、HDR、AMD 颜色、完整 AC/DC 游戏配置等仍待补齐。

## 逐项核对方式

1. 相同 Windows 缩放、主题、显示模式下打开原程序和 LegionGoBar，核对每页默认状态、展开内容、焦点、弹窗和控件尺寸。
2. 首先运行只读 `--diagnose`，保存 WMI/HID/AMD 可用能力。
3. 在掌机上逐项操作，记录请求值、实际回读、物理响应、重启后持久化、游戏切换与 AC/DC 切换。
4. 对不具备回读协议的操作记录物理证据，不以“已发送”当作成功。
5. 只有全部必需项通过才能将 full_parity_accepted 改为 true；目前不应修改此标记。
